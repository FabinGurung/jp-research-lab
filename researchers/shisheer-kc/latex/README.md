# Shisheer KC — modular LaTeX working source

The latest **review** source is a navigable, uncompressed Google Drive folder:

- [Editable source folder](https://drive.google.com/drive/folders/16CGSyl9K-Uv_HDXfs9FFRYVAT4I5aSFJ)
- [Main LaTeX entrypoint](https://drive.google.com/file/d/15ypuPdmW3QA7NcDdbCqgOYHTMjxLKtN-/view)
- [CKPT15 cumulative compiled PDF, prior to this template migration](https://drive.google.com/file/d/1AXauW85Gf_nD5Bd5AzdcZRcEHSAM9SB_/view)

The physical source folder separates front matter, chapters, subsections, figures, bibliography, data lineage and reproducibility scripts. It imports the single [PU MSc shared style](../../../controls/latex/template/pumlsc-shared.sty) **v2.6.4**, blob `6deb30ec415fd386de104c0b7248eb9ea8b98ece`, using the TeX search path. No shared style or licensed Times New Roman font binary is copied into this project source.

**Release boundary:** CKPT14 remains the approved scientific baseline. CKPT15 includes researcher Corrections 1–12 but remains under human review. The linked 58-page CKPT15 PDF was compiled using the previous local template; a PDF rendered from the new global style has **not** yet been verified or released. Do not treat the source migration as completed PDF format parity, or repoint the live scientific checkpoint without separate approval. Historical ZIPs remain preserved for reproducibility.
