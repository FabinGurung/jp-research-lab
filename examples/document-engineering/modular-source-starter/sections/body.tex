\section*{Example of a modular enterprise document}
This is a fictional demonstration of a browsable, unzipped source project.

The project entry point is \texttt{main.tex}; the real document body lives in
\texttt{sections/body.tex}. For a long thesis, use
\texttt{chapters/chapter01\_introduction.tex} and subsequent chapter files.

A buildable source folder is not a signed or legally reviewed document.
